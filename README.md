# 국궁 145m 시뮬레이터 — 설치형 웹앱 올리기 안내

이 폴더의 파일을 무료 웹 공간에 올리면, 누구나 주소로 열고 **홈 화면에 앱처럼 설치**할 수 있습니다.
Claude 계정이 없어도 되고, 한 번 열어 두면 **인터넷이 없는 활터에서도** 작동합니다.

## 폴더에 든 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 시뮬레이터 본체 (시사 5발 · 시지 · 환경 3D) |
| `manifest.webmanifest` | 앱 이름·아이콘 정보 (홈 화면 설치용) |
| `sw.js` | 오프라인 작동용 파일 |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |

> 다섯 파일을 **모두 같은 폴더에 그대로** 올려야 합니다. 이름을 바꾸지 마세요. (이 안내 파일은 올리지 않아도 됩니다.)

---

## 방법 A. GitHub Pages (무료 · 주소가 계속 유지됨, 추천)

1. **github.com** 에서 무료 계정을 만들고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**
   - Repository name: 예) `gukgung` (영문)
   - **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 위 다섯 파일을 끌어다 놓고, 아래 **Commit changes** 를 누릅니다.
5. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / 폴더 **/(root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다.
   예) `https://아이디.github.io/gukgung/`
   이 주소가 앱 주소입니다. 다른 사람에게는 이 주소만 알려 주면 됩니다.

## 방법 B. Netlify (끌어다 놓기)

1. **app.netlify.com** 에 무료 가입 후 로그인합니다.
2. **Add new site → Deploy manually** 를 고르고, 이 폴더(파일 다섯 개가 든 폴더)를 통째로 끌어다 놓습니다.
3. 만들어진 주소(예: `https://○○○.netlify.app`)가 앱 주소입니다. 사이트 설정에서 주소 이름을 바꿀 수 있습니다.

> 주의: 파일을 컴퓨터에서 바로 더블클릭해 열면 홈 화면 설치·오프라인 기능이 작동하지 않습니다. 반드시 위처럼 웹에 올린 **https 주소**로 여세요.

## 아이폰 · 아이패드에 설치

1. **Safari** 로 앱 주소를 엽니다. (처음 한 번은 인터넷 연결 필요 — 3D 화면까지 한 번 열어 두면 좋습니다)
2. 아래(아이패드는 위)의 **공유 버튼** → **홈 화면에 추가** → **추가**
3. 홈 화면의 **국궁 시지** 아이콘으로 열면 주소창 없이 전체 화면으로 열립니다.

안드로이드: Chrome으로 주소를 열고 메뉴(⋮) → **홈 화면에 추가**(또는 **앱 설치**).

## 쓰면서 알아 둘 것

- **기록은 각자 기기에 저장됩니다.** 다른 사람과 섞이지 않습니다. 기기를 바꿀 때는 ⚙ 설정 → **기록 내보내기 / 가져오기** 를 쓰세요.
- **시지 이미지 저장**: 시지 화면의 "🖼 시지 이미지로 저장" → "앨범 / 파일로 저장" → 공유 창에서 **이미지 저장** 을 고르면 사진 앨범에 들어갑니다. (미리보기 이미지를 길게 눌러 "사진 앱에 저장"도 됩니다.)
- 첫 실행을 인터넷 없이 하면 3D 화면만 안 보이고 나머지는 작동합니다. 인터넷이 될 때 한 번 열면 그다음부터 오프라인에서도 3D가 보입니다.

## 새 버전으로 바꾸기

1. 새로 받은 `index.html` (필요하면 다른 파일도)을 같은 저장소/사이트에 덮어써서 올립니다.
2. `sw.js` 맨 위의 `const VERSION = 'gukgung-v1';` 숫자를 하나 올립니다(예: `gukgung-v2`).
3. 쓰는 사람들은 인터넷이 될 때 앱을 한 번 열었다 닫으면 새 버전으로 바뀝니다.
